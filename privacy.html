プライバシーポリシー

「雑学アーカイブ」（以下「当サイト」）が、閲覧した方の情報をどのように扱うかの説明です。制定日: 2026年11月9日

当サイトが扱う情報

端末に保存する設定と記録

表示設定と読むための記録を、端末のブラウザにだけ保存します

  • 保存するもの

    文字の大きさと配色の設定、「あとで読む」で保存した記事、読んだ記事と読み進んだ位置、トップページで前回までに見た記事の番号（「新着」の印に使います）

    氏名やメールアドレスなど、個人を特定する情報は含みません

  • やめる・消す

    メニューの「この端末の記録」で、読んだ記事の記録をやめること、保存した記事と記録を消すことができます

  • 保存先

    ブラウザの localStorage（端末の中）

    当サイトのサーバーや外部には送られません。ブラウザのサイトデータを消すと元に戻ります

  • 当サイト自身の解析

    当サイトのページには、アクセス解析のスクリプトを入れていません

サーバーのアクセスログ

当サイトは GitHub Pages で配信しており、配信元の GitHub がログを扱います

  • 扱い

    IPアドレスなどの記録は、GitHub のプライバシーに関する声明に従って扱われます

    GitHub のプライバシーに関する声明

広告配信事業者の Cookie

当サイトは、第三者配信の広告サービス（Google AdSense）を利用することがあります

  • Cookie の利用

    Google などの第三者配信事業者は、Cookie を使って、当サイトや他のサイトへの過去のアクセス情報にもとづいた広告を表示します

    Cookie には、氏名・住所・メールアドレス・電話番号は含まれません

  • パーソナライズ広告を無効にする

    Google の広告設定で無効にできます。また、www.aboutads.info で、第三者配信事業者の Cookie を使ったパーソナライズ広告を無効にできます

  • Google の取り扱い

    Google が広告で情報をどう使うかは、Google の広告に関するポリシーと規約に書かれています

  • 現在の状況

    2026年11月9日時点では、広告はまだ掲載していません。掲載を始めたときは、このページを更新します

外部サイトへのリンク

記事の出典などで、公的機関や企業の外部サイトにリンクしています

  • リンク先での情報の扱い

    リンク先のサイトでの情報の扱いは、それぞれのサイトの方針に従います

    当サイトから、閲覧した方の情報をリンク先に渡すことはありません

お問い合わせで受け取る情報

お問い合わせは GitHub の Issue で受け付けており、書き込みは公開されます

  • 注意

    Issue に書いた内容と GitHub のアカウント名は、誰でも見られます。個人情報は書かないでください

    お問い合わせ（GitHub Issues）
