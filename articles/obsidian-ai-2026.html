Obsidianと生成AIを組み合わせる方法：3つのやり方、費用、プライバシーの注意（2026年版）

  • 調査日: 2026年11月9日
  • 仕事・学習の道具

要点まとめ

  • Obsidianのノートは、フォルダに入ったMarkdownのテキストファイル[1]
  • AIとの組み合わせ方は、プラグイン・外のAI・自分のPCの3通り（筆者の整理）
  • AI関連で最も多いプラグインCopilotは、約337万ダウンロード[2]
  • APIは使った分だけ払う。Sonnet 5.5は100万トークンで入力2ドル[3]
  • 個人向けのClaudeは、会話を学習に使うかを利用者が選ぶ方式[4]

Obsidianにためたメモを、生成AIで要約したり、関連するノートを探したり、質問に答えさせたりする使い方が広がっています。この記事では、ObsidianとAIを組み合わせる方法を3つに分けて、それぞれの違い、費用、プライバシーの注意点を公式情報でまとめました。特定の製品をすすめるものではありません。Obsidianの基本はObsidianの始め方と注意点にまとめています。

ObsidianとAIの関係

ノートはただのテキストファイル。だから外のAIからも読める

ノートは、パソコンのフォルダ（保管庫）に入ったMarkdownファイル

Obsidianは、ノートをMarkdown形式のテキストファイルとして、パソコンのフォルダ（保管庫）に保存します[1]。ほかのテキストエディタでも編集でき、外での変更はObsidianに自動で反映されます[1]。Obsidianのデータはパソコンに保存され、運営元のサーバーには送られないとしています[5]。

Obsidian本体には、AIの機能が見当たらない

公式のロードマップと変更履歴に、AIの機能は見当たらなかった

2026年11月9日時点の公式のロードマップと変更履歴には、AIの機能は見当たりませんでした[6][7]。例外として、公式のブラウザ拡張「Web Clipper」のInterpreterは、言語モデルでウェブページを要約・抽出する機能です[8]。データは利用者が選んだAIの提供元に送られ、Obsidianは要求のデータを集めたり保存したりしないとしています[8]。

方法1：Obsidianの中でプラグインを使う

AIに関係する主なコミュニティプラグイン（ダウンロード数は2026年11月9日時点）
プラグインダウンロード数主にできること公式ディレクトリのReview表示
Copilot3,367,227保管庫の中でAIに質問、意味での検索、エージェント[9]Satisfactory[9]
Claudian2,659,888保管庫を作業場所にして、Claude Codeなどを埋め込む[10]Satisfactory[10]
Smart Connections1,265,240書いているノートに関連するノートを表示[11]Satisfactory[11]
Local REST API with MCP844,861保管庫を、外のAIから読み書きできるようにする[12]Satisfactory[12]
Text Generator593,657アイデア・題名・要約などの文章を作る[13]Caution[13]

ダウンロード数の出典: Obsidianの公式GitHubの統計[2]。プラグイン自体は入れられても、多くはAIの提供元のAPIキーや契約が別に必要です（筆者の見解）。Smart Connectionsは、内蔵のモデルを使えばAPIキーなしで関連ノートを探せます[14]。Copilotには、任意の有料機能があります[9]。

入れる前に、プラグインの権限と評価を確かめる

プラグインはファイルにもネットにもアクセスできる

Obsidianは、初期設定では外部のプラグインを動かさない「制限モード」になっています[15]。公式ヘルプは、コミュニティプラグインはファイルにアクセスでき、インターネットに接続でき、追加のプログラムを入れることもできると説明しています[15]。機密のデータを扱うなら、独自にセキュリティの確認をするよう勧めています[15]。

くわしく
  • 公式ディレクトリは、自動の点検結果をHealthとReviewの評価で表示する[16]
  • Reviewには、外部のサーバーへの送信などが開示事項として載る[16]
  • Smart ComposerとLocal GPTのReview表示は、調査日時点でRisks[17][18]

方法2：外のAIに、ノートのフォルダを読ませる

MCPは、AIを外のデータにつなぐ共通の規格

MCPは「AIアプリ用のUSB-C」のような共通の差し込み口

MCP（Model Context Protocol）は、AIアプリを外部のシステムにつなぐためのオープンな規格で、公式はUSB-Cの差し込み口にたとえています[19]。Claude Desktopでは、ファイルを扱うMCPサーバーを入れて、読ませるフォルダを設定で指定します[20]。AIがファイルを操作する前には、利用者の承認が必要です[20]。保管庫のフォルダだけを指定すれば、AIに見せる範囲を絞れます（筆者の見解）。

くわしく
  • Claude Desktopのファイル用MCPサーバーには、Node.jsが必要[20]
  • エディタのCursorも、MCPで外部のツールやデータにつなげる[21]
  • プラグイン「Local REST API with MCP」は、保管庫をMCPサーバーとして外に公開する[22]

Claude Codeは、フォルダの中のファイルを直接読み書きする

ファイルの読み書きやコマンドの実行まで行うAIの道具

Claude Codeは、フォルダの中のファイルを読み、編集し、コマンドを実行するAIの道具で、使うにはClaudeの有料プランか、Anthropic Consoleのアカウントが必要です[23]。保管庫のフォルダで使えば、ノートの整理や下書きを頼めます（筆者の見解）。なお、Anthropicは、第三者の開発者が自分のアプリでClaude.aiのログインを提供することなどを認めないと規約に書いています[24]。

方法3：自分のパソコンでAIを動かす

ローカルLLMなら、ノートをパソコンの外に出さない

Ollamaは、自分のパソコンで動かすなら無料

Ollamaは、AIのモデルを自分のパソコンで動かすためのソフトで、パソコンで動かす分は無料です[25]。パソコンで動かすときは、運営元はプロンプトやデータを見ないとしています[26]。対応するのは、Windows 10 22H2以降、macOS 14（Sonoma）以降などです[27][28]。

くわしく
  • Ollamaのクラウドのモデルは別料金で、Proは月20ドル[25]
  • どれくらいのメモリが必要かの公式の目安は、調査では見つからなかった
  • パソコンの性能によって、動かせるモデルの大きさや速さが変わる（筆者の見解）

費用の考え方

AnthropicのAPIの料金（100万トークンあたり、米ドル、2026年11月9日時点）
モデル入力出力
Claude Fable 5.110ドル50ドル
Claude Opus 5.54ドル20ドル
Claude Sonnet 5.52ドル10ドル
Claude Haiku 5.5（10万トークン以下）0.10ドル0.50ドル

出典: [3]。APIは、送った文章（入力）と返ってきた文章（出力）の量に応じて払う仕組みで、料金は米ドルで表示されています[3]。OpenAIのAPIも、100万トークンあたりの料金で、モデルごとに値段が違います[29]。

月額のプランは、税別の米ドル表示

ClaudeのProは月20ドル（年払いなら月17ドル相当）

Claudeの個人向けの有料プランは、Proが月20ドル（年払いなら月17ドル相当）、Maxが月100ドルで、表示の価格には税が含まれていません[30]。ChatGPTの月額は、公式ページの金額を調査で読み取れませんでした。

くわしく
  • Claude 4.7以降のモデルは、同じ文章でもトークンを約30%多く数える[3]
  • 同じ文章量でも、モデルによって料金の計算が変わる（筆者の見解）

プライバシーと安全

入力した内容が、AIの学習に使われるか
サービス初期設定での扱い
OpenAIのAPI2023年3月1日から、送ったデータを学習に使わない（自分で許可した場合を除く）[31]
AnthropicのAPIなど商用向け入力も出力も、初期設定では学習に使わない[32]
Claudeの個人向け（Free・Pro・Max）学習に使うかを利用者が選ぶ。許可すると保存期間は5年、しないと30日[4]
Ollama（自分のパソコン）運営元はプロンプトやデータを見ない[26]

個人情報保護委員会の注意

入力した個人情報が、AIの学習に使われることがある

個人情報保護委員会は2023年6月に、入力した個人情報が生成AIの学習に使われ、正確または不正確な内容で出力されるおそれがあるとして、一般の利用者に注意を呼びかけました[33]。サービスの利用規約やプライバシーポリシーを十分に確認したうえで判断するよう求めています[33]。他人の名前や連絡先、仕事の機密が入ったノートは、AIに読ませる保管庫と分けておくと安心です（筆者の見解）。

今回確認できなかった点

  • ChatGPTの月額と、学習に使わない設定の公式の説明（公式ページを読めなかった）
  • Claudeの料金の日本円での表示
  • Obsidianが「AIの機能を入れない」と明言した公式の文
  • ローカルLLMに必要なメモリの公式の目安
  • 公式ディレクトリで、各プラグインの評価がその表示になった理由
