このサイトについて

「雑学アーカイブ」は、暮らしの制度やお得、おでかけ、学び、仕事の道具まで、気になったことを調べて、短く読める形でまとめているサイトです。

運営者

個人で運営しています

特定の企業・団体には属していません。2026年11月に公開しました

  • 運営者

    雑学アーカイブ 運営者（個人）

    氏名・所在地は、個人情報を載せない方針のため公開していません

  • 記事を書く人

    運営者が、公的機関・公式サイトの資料を読んで書いています

    専門家（税理士・社会保険労務士・医師など）ではありません。個別の判断は専門家や窓口に相談してください

  • お問い合わせ

    GitHub の Issue で受け付けています（誤りの指摘・取り上げてほしいテーマなど）

    お問い合わせ（GitHub Issues）。書き込みは公開されるので、個人情報は書かないでください

記事の作り方

事実には出典を付ける

制度・金額・期限・条件などの事実には、すべて出典を付けています

  • 出典の優先順位

    ① 公的機関 → ② 公式サイト → ③ 信頼できる報道機関 → ④ その他（参考扱い）

    個人ブログ・SNS・まとめサイトだけを根拠にはしません

  • 本文中の [1] などの番号

    マウスを乗せる・タップすると、出典が吹き出しで表示されます

    記事の末尾の「出典」を開くと一覧で見られます

  • 意見と事実の区別

    推測や提案には「筆者の見解」「筆者の提案」と書いています

    公式情報で確認できなかった点は、各記事の「今回確認できなかった点」にまとめています

  • 写真・画像

    自由に使えるライセンスの写真（Wikimedia Commons など）や、利用が認められた公式資料の画像だけを使っています

    作者・出典・ライセンスは、各記事の末尾の「写真・画像の出典」にまとめています（記事一覧の小さな写真は、記事の写真を切り抜いて縮小したもので、出典はトップページの末尾にあります）

調査日を明記する

各記事の冒頭に調査日と、そこからの経過日数を表示しています

  • 変わりやすい情報

    期限・条件・価格（税込／税抜）を明記しています

    制度・キャンペーン・価格は、調査日のあとに変更・終了されることがあります

  • 更新したとき

    「更新日」を追加し、何を更新したかを記事内に残します

便利な使い方

読みやすさのための機能

詳しい説明は「くわしく」に折りたたんでいます

  • くわしく／すべて開く

    項目ごとの「くわしく」を押すと開きます。目次の下のボタンで一度に開閉できます

    印刷するときは自動ですべて開きます

  • 表示設定

    画面右上の「メニュー」から、文字の大きさ（標準／大きめ）と配色（自動／ライト／ダーク）を変えられます

    設定はこの端末のブラウザにだけ保存されます

  • メニュー

    画面右上の「メニュー」に、記事の検索、カテゴリの一覧、各ページへのリンク、表示設定をまとめています

    記事を読んでいるときは「この記事の目次」も出て、いま読んでいる章が分かります。パソコンの広い画面では、本文の右にも目次が出ます

  • 記事を探す

    トップページで、キーワード検索とカテゴリでの絞り込みができます。題名と説明のほか、記事の中の見出しと要点も探します

    キーワードを空白で区切ると、すべてを含む記事だけに絞れます。一致した見出しがカードの下に出て、その章へ直接移れます（対応しているブラウザでは、探した語に色が付きます）。絞り込んだ状態は、そのままURLで共有できます

  • 並び順・おまかせ

    記事一覧は「カテゴリ別」「新しい順」「古い順」を切り替えられます

    「おまかせで1本読む」を押すと、記事を1本選んで開きます（絞り込み中は、その中から選びます）

  • 続けて読む

    記事の最後に、内容の近い「関連する記事」が出ます（ほかのカテゴリの記事も含みます）

    記事の上の「トップ › カテゴリ名」からも、同じカテゴリの一覧に移れます

  • あとで読む

    記事の題名の下の「あとで読む」を押すと、その記事を保存できます

    保存した記事は、トップページの「保存した記事」やメニューから一覧できます。もう一度押すと取り消せます

  • 続きから読む

    途中まで読んだ記事を開くと、前回読んでいた章へ移るボタンが出ます

    記事一覧には「読みかけ」「読了」の印と、前回の訪問より後に追加された記事の「新着」の印が付きます

  • 共有

    記事の冒頭のボタンで、記事のリンクを共有・コピーできます

    見出しの横の「#」を押すと、その見出しへのリンクをコピーできます

  • 誤りを知らせる

    記事の最後のリンクから、誤りや古くなった内容を GitHub の Issue で知らせることができます

    Issue は公開の場です。個人情報は書かないでください

  • 新着を受け取る

    新しい記事は RSS で配信しています（新しい順に30件）

    RSS リーダーに登録すると、追加された記事を確認できます

広告と個人情報の扱い

アクセス解析は入れていません

当サイト自身が閲覧した人の情報を集める仕組みはありません

  • 設定と記録の保存

    文字の大きさ・配色の設定と、「あとで読む」・読んだ記事の記録を、閲覧している端末のブラウザ（localStorage）にだけ保存します

    サーバーには送られません。メニューの「この端末の記録」で、記録をやめる・消すことができます

  • 広告

    運営費にあてるため、第三者配信の広告（Google AdSense）を掲載することがあります

    広告配信に使われる Cookie と、無効にする方法はプライバシーポリシーに書いています。2026年11月9日時点では、まだ掲載していません

  • 記事の内容

    個人を特定できる情報は掲載しません。広告主や企業から対価を受けて書いた記事はありません

免責事項

掲載情報は各記事の調査日時点のものです。正確性には注意していますが、内容を保証するものではありません。掲載情報を利用したことによる損害について、責任を負いかねます。くわしくはプライバシーポリシーの免責事項を見てください。
